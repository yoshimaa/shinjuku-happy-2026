# shinjuku-happy-2026

新宿区 商店街ハッピー商品券の取扱店検索アプリ

> 本アプリは非公式です。最新・正確な情報は[公式サイト](https://shinjuku-happy.jp/)をご確認ください。

## 商店街ハッピー商品券とは

新宿区商店会連合会が、商店街の活性化と区民の生活応援を目的に発行する紙の商品券です。1冊10,000円で、13,000円分の買い物ができます（1冊あたり3,000円お得）。

| 券種 | 金額 | 使える店舗 |
|---|---|---|
| 応援券 | 8,000円分（500円×16枚） | 中小企業・個人店の取扱店 |
| 共通券 | 5,000円分（500円×10枚） | すべての取扱店 |

- 発行冊数：15万冊
- 大手企業の百貨店・大型商業施設に入居する店舗は、共通券のみ利用できます。
- たばこ、医療保険・介護保険の支払い、換金性の高いもの（商品券・切手・プリペイドカード等）、税金・公共料金の支払いなどには使えません。

## アプリの仕様

### 画面構成

- 地図（MapLibre GL JS ＋ OpenFreeMap Liberty を日本語化したスタイル）と店舗一覧の2画面構成です。
  - スマートフォン（幅900px未満）：一覧は下から出るシートです。高さは「初期」「現在地取得後の半分」「全画面」の3段階で、持ち手のドラッグ・フリックで切り替えます。一覧を下へスクロールしている間は、分類バーと現在地ボタンを隠します。
  - PC（幅900px以上）：一覧を左の固定パネルに表示します。
- 地図は新宿区の範囲だけを表示し、範囲外へは移動できません（ズーム12〜18）。
- ホーム画面に追加できるよう Web App Manifest とアイコンを用意しています。Service Worker はないため、オフラインでは使えません。

### 表示する店舗と初期状態

- 初期状態は「応援券が使える店舗」だけを表示します。
- 複数の商店会に重複掲載されている店舗（店舗名と住所が同じ2件目以降。削除フラグ=1）は、どの条件でも表示しません。データからは消さずにフラグで除外します。
- 店名などの全角英数字は、表示時に半角へ揃えます（長い店名が何行にも折り返されないようにするため。括弧は全角のまま）。

### 並び順と現在地

- 起動時に現在地を自動で取得し、取得できたら現在地周辺へ地図を移動して、一覧を近い順に並べます。取得までは牛込保健センター（新宿区弁天町50）周辺を表示します。
- 自動取得が終わる前に店舗の選択・一覧のスクロール・地図の操作などをしていた場合は、現在地の記録とマーカーの表示だけにとどめます。地図の位置・選択中の店舗・一覧の閲覧位置は動かさず、近い順への並べ替えは次に一覧が更新されたとき（検索・絞り込みなど）に反映します。
- 「現在地から探す」を押すと、選択を解除して現在地へ移動し、一覧を近い順で先頭から表示し直します。
- 現在地が新宿区外の場合、距離は意味をなさないため、牛込保健センターに近い順で並べます（距離は表示しません）。
- 現在地がない場合は、公式サイトの掲載順で表示します。
- 一覧は60件ずつ表示し、「さらに表示」で追加します。

### 検索

- 店名・業種（分類を含む）・住所・商店会・エリアを対象に検索します。
- 表記ゆれを吸収します。
  - 全角／半角、カタカナ／ひらがな、小書き文字（ぁ→あ など）を同一視します。
  - 「ヶ／が」入りの地名（市ヶ谷・市が谷→市谷）、漢数字の丁目（三丁目→3丁目）、丁目・番地などの表記を揃えます。
  - 空白・記号は無視します。
- 空白で区切った語は、すべてを含む店舗（AND）に絞り込みます。よく使う言い換え（床屋＝理容、本屋＝書店、スタバ＝スターバックス など）でもヒットします。
- 並び順は一致度順（店名で一致＞業種・分類で一致＞住所・商店会・エリアで一致。店名の先頭一致を優先）で、同点なら近い順です。
- 全店舗の中に一致する店舗が1件もない場合（打ち間違い・うろ覚え）だけ、文字の並びが似た店舗を「似た店舗」として表示します。絞り込みの結果0件になった場合は、条件に合わないだけなので似た店舗は出しません。
- 検索と絞り込みの関係
  - 検索を始めると、券種を含むすべての絞り込みを外し、全店舗を対象にします。
  - 検索中に選んだ分類・券種は、検索結果にかけ合わせます。分類バーや絞り込み画面の件数も、検索結果の中での件数です。
  - 検索語を空にする（または ✕ で消す）と、初期状態（応援券が使える店舗）に戻ります。

### 分類と絞り込み

- 地図上の分類バーで、大分類（7種）を1タップで切り替えます（単一選択。もう一度押すと解除）。中分類が複数ある大分類を選ぶと、中分類のバーも表示します。
- 分類バー右端の「詳細設定」、または検索欄横のボタンで絞り込み画面を開きます。
  - 券種：選んだ券種がすべて使える店舗を表示します。
  - 分類：大分類・中分類を複数選択できます。
  - 「結果を表示」を押すまで反映しません。閉じるボタン・Escape・背景のクリックで閉じた場合、変更は捨てます。
  - 「リセット」は画面上の選択だけを戻します。検索中は「絞り込みなし」、通常時は初期状態に戻り、検索語は残します。
- エリア・商店会はデータとして持ち、検索の対象にしていますが、絞り込みの条件には使いません。
- 条件を変えて、今の地図の範囲に該当店舗がなくなった場合は、該当店舗が収まるように地図を動かします。

### 地図と店舗の詳細

- 店舗のピンはまとめて表示（クラスター）し、ズーム15より拡大すると個別のピンになります。
- ピンや一覧の店舗を選ぶと、ポップアップに業種・住所・使える券種と、電話・Googleマップ（店名＋住所で検索）・Webサイトへのリンクを出し、一覧の選択と連動させます。
- 住所の緯度経度は建物名を除いた番地までで求めています。そのため、同じビルの店舗や番地のない住所（地下街など）の店舗は同じ座標になり、拡大してもピンが分かれません（多い地点では45店舗が1点に重なります）。ジオコーディングの精度を上げるのではなく、画面側で選べるようにしています。
  - 重なったピンを押すと「この場所の店舗（N件）」として候補を一覧にし、そこから店舗を選びます。候補は表示中の店舗だけです。
  - 店舗の詳細からは「‹ 同じ場所の店舗」で候補一覧に戻れます。
  - 候補一覧は、地図の見えている範囲に収まる高さでスクロールします。

### 地図を使えない場合

- 地図ライブラリを読み込めない、WebGL を使えない、地図スタイルを取得できない場合は、地図を出さずに一覧だけで使えるようにします。
  - 画面に「地図を表示できません」と表示します。
  - 選んだ店舗のカードに、電話・Googleマップ・Webサイトへのリンクを表示します。
- タイルなどの一時的な取得エラーでは地図を止めません。15秒たっても地図が表示されない場合は、読み込み中である旨だけを案内します。

### キーボード操作

- 一覧の店舗は Tab で移動し、Enter／Space で選択できます。
- 絞り込み画面はモーダルダイアログです。
  - 開いている間、フォーカスは画面内にとどまり、背面は操作できません。
  - 開くと閉じるボタンにフォーカスを移します。閉じると、開いたボタンにフォーカスを戻します。
- 重なったピンの候補一覧はボタンで、Tab と Enter で選べます。Escape で閉じます。

## 開発

ビルド不要の静的サイトです。`docs/` をそのまま GitHub Pages で公開します。外部への依存は CDN から読み込み、パッケージ管理や自動テストはありません。

```
docs/                 GitHub Pages の公開ディレクトリ
  index.html
  manifest.webmanifest
  favicon.ico
  assets/css/style.css
  assets/js/app.js     画面のすべての処理（分類の定義・検索の言い換えもここ）
  assets/icons/        ホーム画面・タブ用のアイコン
  assets/map/liberty-ja.json  地図スタイル（生成物）
  data/shops.json      アプリが読み込む店舗データ（生成物）
  .nojekyll
data/                 元データ（公開サイトには含めない）
  shinjuku_happy_shops.csv
  geocache.json        住所→緯度経度のキャッシュ
scripts/
  scrape.py            公式サイト → data/shinjuku_happy_shops.csv（大分類・中分類・削除フラグも付与）
  categories.py        業種 → 大分類・中分類の対応表
  build_data.py        CSV ＋ 緯度経度 → docs/data/shops.json
  build_style.py       OpenFreeMap Liberty → 日本語化・軽量化 → docs/assets/map/liberty-ja.json
```

### 外部サービス

| 用途 | 提供元 |
|---|---|
| 地図ライブラリ | MapLibre GL JS 5.24.0（unpkg） |
| 地図タイル・アイコン・フォント | OpenFreeMap |
| 画面のフォント | Google Fonts（Noto Sans JP） |
| 住所→緯度経度（データ作成時のみ） | 国土地理院 住所検索API |

### ローカルで確認する

```bash
python3 -m http.server 8000 -d docs
```

ブラウザで http://localhost:8000 を開きます。

### 店舗データの更新

公式サイトから取得し直して、アプリ用データを作り直します。

```bash
python3 scripts/scrape.py
```
```bash
python3 scripts/build_data.py
```

- 項番（アプリ内の店舗ID）は、取得時の掲載順に振り直します。取得し直すと同じ店舗でも番号が変わることがあります。
- 緯度経度は国土地理院の住所検索APIで取得し、`data/geocache.json` にキャッシュします（新しい住所だけ問い合わせます）。建物名を除いた番地までで検索します。
- 公式サイトに新しい業種が増えた場合、`scrape.py` が警告を出して「その他」に分類します。`scripts/categories.py` に追加してください。大分類・中分類の名前や並びを変える場合は、`docs/assets/js/app.js` の `CATEGORIES`（表示順・アイコン・色）も合わせて直します。
- データの取得日は画面下部のクレジット（`docs/index.html`）と、この README の「データの出典」に書いています。更新したら日付も直します。

### 地図スタイルの更新

OpenFreeMap の Liberty スタイルから作り直します（地名を日本語表記にし、新宿区だけの表示では使わない国境・空港などのレイヤーを除きます）。

```bash
python3 scripts/build_style.py
```

### GitHub Pages の設定

リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `/docs` にします。
